# Studio de proposta

Modelo público e sanitizado para prévias de propostas de `landing/web`, `automação/IA` e `UX/interface`.

## Abrir cada família

- `index.html?modelo=landing`
- `index.html?modelo=automacao`
- `index.html?modelo=uxui`

## Editar

1. Abra `config.js`.
2. Altere a família correspondente: textos, imagem de referência, etapas, itens editáveis e checklist do briefing.
3. Não use nome, logo, foto ou dado não autorizado de um cliente. A faixa superior deve continuar identificando a página como conceito ilustrativo até haver autorização documentada.
4. Teste em 320px, 768px e desktop antes de usar o link em uma proposta.

Não há formulário, rastreador ou dado pessoal neste modelo.
