# Vitrine e demonstração

Página estática de apresentação profissional e uma demonstração de correção de responsividade.

- `index.html` — ofertas, processo, limites e contato.
- `demo/cafe-aurora.html` — versão corrigida de uma página de demonstração. Empresa fictícia, declarada como tal.
- `demo/cafe-aurora-antes.html` — a mesma página com os defeitos de celular que a correção resolve.

Sem dependências externas, fontes remotas, scripts de terceiros ou rastreadores. Para abrir localmente, basta servir a pasta ou abrir `index.html` no navegador.

Publicado com GitHub Pages a partir da raiz do branch `main`.

## Como sugerir código

Ideias de UX/UI, acessibilidade, responsividade e novas demonstrações podem ser abertas como [issue de melhoria](../../issues/new?template=feature_request.yml). Para problemas visuais ou links quebrados, use o [modelo de bug](../../issues/new?template=bug_report.yml). A [guia de contribuição](CONTRIBUTING.md) explica como validar em celular e desktop.
