# Atendea — demo de atendimento com IA e transferência humana

Protótipo público criado para a oportunidade Workana “Desenvolvimento de Bot de Resposta Automática com IA para WhatsApp”. Marca, conversa, indicadores e respostas são fictícios.

## O que a demonstração mostra

- três cenários de conversa simulada: horário, cardápio e transferência para atendimento humano;
- edição local do nome e das respostas de exemplo, persistida apenas no navegador;
- uma interface responsiva para revisar fluxos e conteúdo;
- indicação explícita de que a API do WhatsApp e o modelo de IA não estão conectados.

## Abrir

Abra `index.html` em um navegador. A demonstração não envia mensagens e não transmite o conteúdo editado.

## Limite do protótipo

Uma implantação real depende de requisitos definidos com o cliente, credenciais de API oficial, hospedagem, política de dados, teste das respostas e monitoramento. Os valores da interface são apenas conteúdo de exemplo, não métricas de produção.
