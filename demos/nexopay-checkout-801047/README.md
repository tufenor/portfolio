# NexoPay — conceito de UX para checkout e pagamentos SaaS

Estudo independente preparado para demonstrar hierarquia de checkout, acesso e painel financeiro responsivo. Não é projeto contratado, produto real nem experiência de um cliente.

## O que está no protótipo

- Checkout com resumo, parcelas, campos essenciais, estado seguro e prévia desktop/celular.
- Tela de acesso com estados de formulário e opção de exibir senha.
- Painel com indicadores, gráfico e atividade de exemplo.
- Navegação local, controles demonstrativos e layout adaptado a telas pequenas.
- Marcação explícita de conteúdo, pessoas, produtos e métricas fictícias.

## Limites

Nenhum formulário envia dados; não existe integração de autenticação, gateway, cartão, cobrança ou analytics. Todos os números são ilustrativos, não são resultados medidos. O conceito não usa marca, conteúdo ou ativos do anunciante da oportunidade.

## Execução local

Abra `index.html` em um navegador. A demonstração usa Google Fonts; o restante é HTML, CSS e JavaScript estático.
