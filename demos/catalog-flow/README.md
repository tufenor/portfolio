# Catálogo Studio — demonstração interativa

Protótipo conceitual para o projeto 3RQCS549 do Freelancer.com.br. Demonstra importação local de CSV, seleção de uma ficha, edição de título e descrição, revisão e exportação de JSON.

## Interações

- Selecionar produtos com fotografia de referência relacionada à categoria.
- Alterar localmente os dados da ficha e conferir a imagem correspondente no painel de detalhes.
- Importar CSV; a categoria e o nome orientam a seleção de uma imagem ilustrativa.
- Simular uma sugestão de texto predefinida, marcar aprovação somente na demonstração e exportar JSON.
- Buscar, filtrar e ordenar a lista.

## Imagens e limites

Produtos, marca, preços, estoque e dados são fictícios. As fotos são referências visuais; não representam os itens nem comprovam atributos. Troque-as por fotografias autorizadas do catálogo antes de publicar. A sugestão de texto é conteúdo de exemplo e não chama uma IA. Mercado Livre e ERP não estão conectados; não existe backend, login ou publicação externa. Edições ficam no navegador até exportar o JSON.
