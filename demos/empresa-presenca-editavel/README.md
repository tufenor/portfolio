# Nortea — demonstração de site institucional editável

Página conceitual em HTML, CSS e JavaScript para demonstrar uma presença digital responsiva de empresa de serviços.

- Marca, texto e serviços são fictícios.
- Imagens ilustrativas carregadas do Unsplash; troque por imagens licenciadas ou fornecidas pela empresa antes da produção.
- O botão **Personalizar prévia** altera apenas o navegador atual; a opção de exportar baixa um JSON com o conteúdo editado.
- O formulário é apenas demonstrativo e não envia dados. Conectar WhatsApp, e-mail ou CRM exige configurar um destino real com o cliente.
- Não há métricas, clientes, depoimentos ou resultados comerciais inventados.
- O código é independente, sem backend e sem dependências de execução.

## Adaptar

Edite `site-data.js` para alterar textos e cor padrão. Substitua as URLs das imagens, revise o texto alternativo e escolha o canal de contato real antes da publicação de um cliente.

Demo: https://tufenor.github.io/portfolio/demos/empresa-presenca-editavel/
