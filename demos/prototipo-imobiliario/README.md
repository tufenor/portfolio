# morada — protótipo imobiliário

Demonstração conceitual navegável para portfólio, inspirada em um pedido público de protótipo de app imobiliário. Não foi feita para o cliente nem representa experiência comercial anterior.

## O que dá para explorar
- Busca visual por cidade ou bairro.
- Filtros por categoria e faixa de preço.
- Alternância de mapa ilustrativo.
- Favoritos salvos somente no navegador local.
- Detalhes do imóvel e chamada de solicitação de visita simulada.
- Layout responsivo, estados vazios, foco de teclado e preferência por movimento reduzido.

## Limites da amostra
Dados, valores, localização e imóveis são fictícios. Não há banco de dados, autenticação, integração imobiliária ou envio real de solicitação. Fotos carregam de imagens públicas do Unsplash.

Abrir `index.html` em navegador moderno.
