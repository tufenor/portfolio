O QUE MUDOU

Confiabilidade começa no diagnóstico.

O monitor não promete uma caixa sempre disponível. Ele preserva a causa observada, permite retry no ciclo seguinte e diferencia conexão de autenticação.

01

Estados independentes

Chrome e Gmail API têm arquivos de estado próprios; o agregador guarda ambos sem concorrência de escrita.

02

Retomada previsível

A rotina do Windows continua no ciclo de 30 minutos e tenta o fallback configurado sem abrir login silencioso.

03

Dados mínimos

O painel precisa do estado, horário e ação necessária. Conteúdo de mensagens e credenciais não fazem parte desta tela.

EVIDÊNCIA DE IMPLEMENTAÇÃO

O que foi verificado no ambiente local.

O ciclo Python retornou `gmail_api_setup_required`; o Chrome reportou `waiting_for_gmail`. O endpoint de saúde da Mesa respondeu HTTP 200. O bundle de produção React/TypeScript foi reconstruído. Nenhum resultado do painel é tratado como aceite de cliente ou receita.
