# Segurança da publicação

Este repositório é uma vitrine estática pública. Ele não deve conter:

- tokens, chaves de API, cookies, senhas ou arquivos `.env`;
- documentos de identidade, dados bancários ou caminhos locais;
- dados privados de clientes além de informações empresariais já usadas nos links públicos de contato;
- páginas de administração, editores locais ou integrações com sistemas de produção.

As demos são exemplos sanitizados. Textos, preços, horários e imagens devem ser confirmados pelo negócio antes de uma entrega real. O GitHub Pages não é um painel administrativo nem um armazenamento de segredos.

Para reportar uma exposição, abra uma issue sem incluir o segredo no texto e descreva apenas o caminho público afetado.
